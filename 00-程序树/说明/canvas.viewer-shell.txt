视图外壳是画布的静态骨架，文件是 00-程序树/工具/viewer/index.html 与 00-程序树/工具/viewer/style.css。它把页面切成顶部页签与标题、工具栏、左侧画布或表格区、右侧详情栏、底部状态条五块，并给关键控件留固定锚点：搜索框 searchInput、画布 canvas 的 graph、详情栏 detail、状态条 statLine、页签容器 gridTabs，渲染脚本靠这些 id 找元素。样式是深色主题，状态色与四类关系的线色都写在 style.css 的根变量里，未完成灰、已完成蓝、已验证绿、退役灰并划线。它的边界是只搭壳不画内容：节点、关系线、组框、详情文字全由 viewer.js 填，它也不读取任何树数据。改动时保持 id 与 class 稳定，否则脚本会静默失效。
