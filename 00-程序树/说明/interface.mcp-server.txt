这个程序负责 MCP stdio 服务的协议面与工具目录。它从 stdin 逐行读 JSON-RPC 2.0 消息，处理 initialize、notifications/initialized、tools/list、tools/call 与 ping，并把批量数组按顺序逐条响应；stdout 只写协议帧，运行日志全部走 stderr，避免污染传输。工具目录里维护 26 个 tree_* 工具，覆盖读、写、校验与备份四组；tools/call 按工具名分发到 NodeTools 或 BackupService，旧名 propose/apply 直接返回 -32601。它不直接读写清单，也不实现校验规则，失败与回滚由内核工具负责。实现集中在 00-程序树/工具/csharp/src/PTree.Mcp/McpServer.cs，内核版本常量在 KernelInfo.cs；改工具时应同时改 ToolDefinitions 的 schema 与 CallTool 分发。
