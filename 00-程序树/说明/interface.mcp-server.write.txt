这个步骤是 MCP 目录里的写工具组，负责把一次节点变更安全落到清单。它覆盖 tree_add_node、tree_add_group、tree_update_group、tree_add_link、tree_update_node、tree_retire_node、tree_relocate、tree_delete 与 tree_commit：新增节点自动推 id、层与组，改字段只动传入项，退役保留理由，迁移与删除处理路径，提交把一次写操作产生的文件归组。它只转发 NodeTools 与 GitSync 的结果，不自己拼 YAML、不跳过校验；每个成功写都要带回新的 tree_version、written_files 与 errors，失败必须由内核回滚。实现位于 00-程序树/工具/csharp/src/PTree.Mcp/McpServer.cs；新增写工具时要先确认内核已有原子写与台账能力。
